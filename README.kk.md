## Бұл не

LWC — vibe — сыртқы тәуелділіксіз ашық құрал (Node.js ≥ 20): CLI және Claude Code плагині.
Ол жүйені түсінуді және нәтижеге бақылауды жоғалтпай, бағдарлама жазу үшін AI пайдалануға
көмектеседі. Агент алдымен талаптарды анықтайды, жоспарды көрсетеді, тәуекелдерді талдайды,
маңызды шешімдерге растау алады, шағын өзгерістерді іске асырады және нәтижені тексереді.
**Anomaly Radar** агенттің сөздерін фактілермен салыстырады: импорт графы, Git күйі, командалардың
нақты іске қосылу жазбалары.

- **Claude Code үшін жеті режим**: Learn, Design, Build, Review, Explain, Anomaly Radar, Resume.
- **Түсіндірудің үш деңгейі**: beginner, intermediate, advanced.
- **Кодқа бақылау**: пайдаланушы шешімдерді растамайынша `lwc task stage build` командасы бас
  тартады; Claude Code хугі кодты мерзімінен бұрын өзгерту әрекетінде растау сұрайды.
- **Сөз орнына дәлел**: `lwc run -- npm test` нақты іске қосуды жазады; сәтті жазбасыз «тесттер
  өтті» мәлімдемесі — PROC-002 табылғаны, сәтсіз іске қосудан кейін — PROC-005.
- **Anomaly Radar**: бес санаттағы 29 ереже — талаптар, архитектура, іске асыру, қауіпсіздік,
  AI-әзірлеу процесі. Әр табылғанда **дереккөз** (ереже, статикалық талдау, тест іске қосу,
  тәуелділіктерді талдау, AI-агенттің пайымдауы) және **күй** (расталған ақау, ықтимал мәселе,
  ескерту, дәлел жеткіліксіз, жалған сигнал — себебімен басылған) көрсетіледі.
- **Операциялық есептерді тексеру** (`lwc ops-check`) бапталатын ережелер бойынша; мысал теңгемен.
- **Есеп және сөйлесу тілдері**: қазақ, орыс, ағылшын. Кириллица мен қазақ әріптері дұрыс өңделеді
  (Unicode сөз шекаралары), сомалар `1 842 000,50 ₸`, `KZT`, `тг` форматтарында қабылданады.
- **Бәрі жергілікті**: сервер, телеметрия, бұлт жоқ. Контекст `.lwc/` каталогында сақталады.

## Орнату

Claude Code плагині (Claude Code сессиясында командаларды біртіндеп):

```text
/plugin marketplace add RuslanKazyradzi13/lwc-vibe
/plugin install lwc-vibe@lwc-vibe
```

CLI:

```bash
npm install -g github:RuslanKazyradzi13/lwc-vibe
lwc init --lang kk --level beginner      # есептер мен түсіндірмелер қазақ тілінде
lwc radar                                # жоба бойынша бірінші есеп
```

## Жұмыс процесінің мысалы

```bash
lwc task start "Қызметкер жеңілдігі 20 %" --scope "src/services/**,tests/**"
lwc decision add "Жеңілдік discount.js ішінде бөлек функциямен есептеледі"
lwc task stage build          # бас тартады: D1 шешімі расталмаған
lwc decision confirm D1       # тек адам растайды
lwc task stage build
lwc run -- npm test           # іске қосу .lwc/evidence/ ішіне жазылды
lwc claim add "Іске асырылды, тесттер өтті"
lwc radar --run-tests --format md --out .lwc/reports/review.md --lang kk
lwc task finish
```

## Демонстрация

```bash
git clone https://github.com/RuslanKazyradzi13/lwc-vibe.git && cd lwc-vibe && npm install
node bin/lwc.js radar examples/demo-buggy-app --lang kk
node bin/lwc.js ops-check examples/ops-report/daily_report.csv --rules examples/ops-report/rules.json --history examples/ops-report/history.csv --lang kk
```

«Кофехана кассасы» демо-жобасында бес санаттың барлығының әдейі енгізілген ақаулары бар (күтілетін
табылғандар — `examples/demo-buggy-app/EXPECTED_FINDINGS.md`). Операциялық есеп демосы міндетті мәннің
жоқтығын, теріс сомаларды, келіспеген қорытындыларды, қайталануларды, мүмкін емес уақыт реттілігін,
тарихқа қатысты секірісті және рұқсат етілген диапазоннан шығуды көрсетеді.

## Қазақстан

Өнім Қазақстандағы командалар үшін ыңғайлы, бірақ елмен шектелмейді: қазақ және орыс хабарлама
каталогтары, KZT мысалдары, `lwc.config.json` және `rules.json` арқылы ережелерді ұйымға бейімдеу.
LWC — vibe Қазақстан Республикасының заңнамасына сәйкестікті **мәлімдемейді** және тексермейді —
толығырақ [docs/KAZAKHSTAN.md](docs/KAZAKHSTAN.md) ішінде.

## Шектеулер

A, C, D санаттарының ережелері — тұрақты өрнектерге негізделген эвристикалар, AST талдауы емес.
JS/TS және Python қолдау табады. Тек Claude Code интеграциясы тексерілген. Қазақша мәтіндерді тіл
иелері редакциялаған жоқ — түзетулерді қуана қабылдаймыз.
