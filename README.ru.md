# LWC — vibe (описание на русском)

**Local Workflow Coach — локальный коуч AI-разработки с Anomaly Radar.**
*ИИ пишет. Ты решаешь. LWC проверяет.*

Основная документация репозитория — на английском: [README.md](README.md), [docs/](docs/).
Этот файл — краткое описание на русском. Казахская версия: [README.kk.md](README.kk.md).

## Что это

LWC — vibe — открытый инструмент без внешних зависимостей (Node.js ≥ 20): CLI плюс плагин Claude Code.
Он помогает использовать ИИ для написания программ, не теряя понимания системы и контроля над
результатом. Агент сначала выясняет требования, показывает план, разбирает риски, получает
подтверждение значимых решений, реализует небольшие изменения и проверяет результат. **Anomaly Radar**
сверяет слова агента с фактами: графом импортов, состоянием Git, записями о реальных запусках команд.

- **Семь режимов** для Claude Code: Learn, Design, Build, Review, Explain, Anomaly Radar, Resume.
- **Три уровня объяснений**: beginner, intermediate, advanced.
- **Контроль над кодом**: команда `lwc task stage build` отказывает, пока решения не подтверждены
  пользователем; хук Claude Code спрашивает подтверждение при попытке править код раньше времени.
- **Доказательства вместо слов**: `lwc run -- npm test` записывает реальный запуск; заявление
  «тесты пройдены» без успешной записи — находка PROC-002, после провалившегося запуска — PROC-005.
- **Anomaly Radar**: 29 правил в пяти категориях — требования, архитектура, реализация, безопасность,
  процесс AI-разработки. У каждой находки указаны **источник** (правило, статический анализ, запуск
  теста, анализ зависимостей, рассуждение AI-агента) и **статус** (подтверждённый дефект, вероятная
  проблема, предупреждение, недостаток доказательств, ложное срабатывание — подавлено с причиной).
- **Проверка операционных отчётов** (`lwc ops-check`) по настраиваемым правилам; пример в тенге.
- **Языки отчётов и общения**: русский, казахский, английский. Кириллица и казахские буквы
  обрабатываются корректно (Unicode-границы слов), суммы принимаются в форматах `1 842 000,50 ₸`, `KZT`, `тг`.
- **Всё локально**: никакого сервера, телеметрии, облака. Контекст хранится в каталоге `.lwc/`.

## Установка

Плагин Claude Code (команды по одной в сессии Claude Code):

```text
/plugin marketplace add RuslanKazyradzi13/lwc-vibe
/plugin install lwc-vibe@lwc-vibe
```

CLI:

```bash
npm install -g github:RuslanKazyradzi13/lwc-vibe
lwc init --lang ru --level beginner      # русский язык отчётов и объяснений
lwc radar                                # первый отчёт по проекту
```

## Пример рабочего процесса

```bash
lwc task start "Скидка сотрудника 20 %" --scope "src/services/**,tests/**"
lwc decision add "Скидка считается отдельной функцией в discount.js"
lwc task stage build          # откажет: решение D1 не подтверждено
lwc decision confirm D1       # подтверждает только человек
lwc task stage build
lwc run -- npm test           # запуск записан в .lwc/evidence/
lwc claim add "Реализовано, тесты пройдены"
lwc radar --run-tests --format md --out .lwc/reports/review.md --lang ru
lwc task finish
```

## Демонстрация

```bash
git clone https://github.com/RuslanKazyradzi13/lwc-vibe.git && cd lwc-vibe && npm install
node bin/lwc.js radar examples/demo-buggy-app --lang ru
node bin/lwc.js ops-check examples/ops-report/daily_report.csv --rules examples/ops-report/rules.json --history examples/ops-report/history.csv --lang ru
```

Демо-проект «касса кофейни» содержит намеренные дефекты всех пяти категорий (ожидаемые находки —
`examples/demo-buggy-app/EXPECTED_FINDINGS.md`). Демо операционного отчёта показывает отсутствующие
обязательные значения, отрицательные суммы, несогласованные итоги, дубликаты, невозможную
последовательность времени, скачок относительно истории и выход за допустимый диапазон.

## Казахстан

Продукт удобен для команд в Казахстане, но не ограничен страной: русский и казахский каталоги
сообщений, примеры в KZT, адаптация правил под организацию через `lwc.config.json` и `rules.json`.
LWC — vibe **не заявляет** соответствие законодательству Республики Казахстан и не проверяет его —
подробнее в [docs/KAZAKHSTAN.md](docs/KAZAKHSTAN.md).

## Ограничения

Правила категорий A, C, D — эвристики на регулярных выражениях, не AST-анализ. Поддерживаются
JS/TS и Python. Протестирована только интеграция с Claude Code. Казахские тексты не вычитаны
носителями языка — правки приветствуются.
